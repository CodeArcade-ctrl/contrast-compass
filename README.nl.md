# Contrast Compass

Een snelle, privacyvriendelijke kleurcontrastchecker voor ontwerpers en ontwikkelaars. Vergelijk tekst- en achtergrondkleuren, bekijk een live voorbeeld en controleer de WCAG 2.2 AA- en AAA-drempels.

**Live demo:** [Probeer Contrast Compass](https://codearcade-ctrl.github.io/contrast-compass/)

**Talen:** [English](README.md) | [Nederlands](README.nl.md)

## Functies

- Live contrastverhouding en tekstvoorbeeld
- WCAG AA/AAA-controles voor gewone en grote tekst
- Kleurkiezer, hex-invoer en voorbeeldpaletten
- Responsieve, toetsenbordvriendelijke interface
- Geen dependencies, accounts, tracking of netwerkverzoeken

## Gebruiken

Open `index.html` in een browser, kies twee kleuren en bekijk de verhouding en vier WCAG-controles. De pagina werkt offline.

## Publiceren met GitHub Pages

Push naar de branch `main`. De meegeleverde GitHub Actions-workflow publiceert de site naar GitHub Pages. Stel bij de repository-instellingen zo nodig **Pages > Build and deployment > Source** in op **GitHub Actions**.

## Toegankelijkheidsnotitie

Contrast is slechts een onderdeel van toegankelijkheid. De tool beoordeelt niet alle visuele of cognitieve behoeften; gebruik kleur nooit als enige manier om betekenis over te brengen. Dit hulpmiddel rapporteert WCAG-contrastverhoudingen en is geen certificering.
